# D-Bus API

This page tells script authors and integrators where the PlasmaZones D-Bus API is and where its reference is.

## Interfaces

The daemon gives all of its functions on `org.phosphor_works.Placement`, for scripts and integration. The API covers
every placement mode. The interface list, scripting recipes and signal watching are in the
**[D-Bus scripting guide](https://phosphor-works.org/plasmazones/dbus/)**.
