# PlasmaZones documentation

This directory holds the documentation pages of PlasmaZones that live in the repository. Users read the install,
use and troubleshooting pages. Developers read the other pages. The user documentation and screenshots are at
[phosphor-works.org/plasmazones](https://phosphor-works.org/plasmazones/).
